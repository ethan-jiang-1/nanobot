# NanoBot 原理文档总览

这个目录用于系统化拆解 NanoBot 的工作原理，目标是从“能跑”到“讲清楚”。

## 目录说明

- `00-overview`：项目目标、核心抽象、全局视角
- `10-main-flow`：从入口到回复的完整执行链路
- `20-agent-core`：Loop、Context、Memory、Session 等核心机制
- `30-tools-and-extension`：工具系统、技能系统、MCP 扩展机制
- `40-channel-layer`：多渠道接入抽象与平台适配
- `50-runtime-services`：定时任务、心跳、后台子任务
- `60-config-and-multi-instance`：配置模型、提供商匹配、实例隔离
- `70-special-topics`：安全边界、容错恢复、调试与可观测性

## 写作基调

- 先讲职责，再讲机制，再讲边界
- 优先解释“为什么这样设计”，再解释“怎么实现”
- 尽量使用时序视角串起跨模块行为
- 每篇文档都回答输入、输出、状态变化、失败路径

## 使用建议

- 按数字顺序阅读，先建立全局心智模型再深入细节
- 章节之间允许交叉引用，但避免重复描述同一段实现
