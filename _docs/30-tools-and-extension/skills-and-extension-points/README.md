# skills-and-extension-points

本目录聚焦 skills 扩展机制：能力发现、可用性判断、上下文注入，以及新能力接入路径。

## 本主题要回答的问题

- workspace skills 与内置 skills 的优先级如何处理
- skill 的依赖条件如何检查并在摘要里暴露
- skill 如何进入 system prompt 且保持按需加载
- 增加新能力时应走哪条扩展路径最稳妥
